# Amatsureika

Главная страница — локальная интерактивная SVG-карта, воссозданная по предоставленным изображению и видео. Без Canvas, WebGL и внешних библиотек визуализации. Три режима: ядро, кольца, соты. Узлы, связи и импульсы демонстрационные, не отражают реальную память.

## Запуск

Windows: установите Python 3 и Node.js, запустите Start.bat. Первый запуск требует сети для установки TypeScript; после установки сборка и сервер работают локально. Или выполните npm install, npm run build, python server.py.

Масштаб — колесо мыши или кнопки; перетаскивание — перемещение карты; клик по кластеру или узлу — подсветка связей. Панель позволяет менять режим, скорость, свечение и плотность линий. При системной настройке reduced motion анимация по умолчанию отключена.

Python — единственный сервер, Node.js используется только для сборки. Настоящая память, SQLite и Cloud.ru пока не подключены.
