# Amatsureika

Главная страница — локальная интерактивная SVG-карта, воссозданная по предоставленным изображению и видео. Без Canvas, WebGL и внешних библиотек визуализации. Три режима: ядро, кольца, соты. Узлы, связи и импульсы демонстрационные, не отражают реальную память.

## Запуск

Windows: установите Python 3.10+ и Node.js LTS с npm, запустите Start.bat. При ошибке окно остаётся открытым; журнал находится в logs/startup.log. Сервер работает, пока открыто окно. Если браузер не запустился, скопируйте адрес из окна. Start.bat --check проверяет запуск сборки без открытия браузера. Первый запуск требует сети для установки TypeScript; после установки сборка и сервер работают локально. Или выполните npm install, npm run build, python server.py.

Масштаб — колесо мыши или кнопки; перетаскивание — перемещение карты; клик по кластеру или узлу — подсветка связей. Панель позволяет менять режим, скорость, свечение и плотность линий. При системной настройке reduced motion анимация по умолчанию отключена.

Python — единственный сервер, Node.js используется только для сборки. Настоящая память, SQLite и Cloud.ru пока не подключены.

## Расширение визуализации
Двойной щелчок по кластеру — плавное приближение, колесо — масштаб 8–6400% с четырьмя уровнями детализации. Настройки скрыты по умолчанию; чат без внешней рамки открывается кнопкой «Чат». В чате доступны локальные команды, а не ответы LLM. В настройках можно добавить узел, связать два последовательно выбранных кластера и создать производный демонстрационный узел без удаления исходных. Данные не сохраняются между перезапусками. Предел — 5000 узлов и 360 на кластер. SVG, без Canvas/WebGL.
